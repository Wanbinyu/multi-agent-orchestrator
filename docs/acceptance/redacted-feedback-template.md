# Redacted Feedback Offline Template (Copy and Use)

If you prefer not to use the GitHub form, copy and fill the sections below into an Issue body, or first run:

```bash
python scripts/sanitize_feedback_text.py draft.txt
```

Full guide: [`docs/external-user-feedback-guide.md`](../external-user-feedback-guide.md).

---

## A. Install / First-Time Setup

```text
【Type】Install feedback
【MAO version】
【OS / Python】
【Install method】pipx / source editable
【Stuck at】install | command not found | first mao | Web | configure Provider | first chat
【Error code】(if any)
【Redacted commands】
【Redacted output】
【Confirmed no Key / no .env / no Session】yes
```

【Result】completed | partial | failed/blocked | abandoned
【Evidence】approx tool count; whether wrote files; error codes; accidental edits
